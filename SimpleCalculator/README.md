# 🧮 Simple Calculator - Task 2

A simple and modern native Android calculator UI application built using **Kotlin** and **XML Layouts**.

---

## 📱 Features & Current Scope

- **Keypad Input Display:** Pressing digits (`0-9`), operators (`+`, `-`, `×`, `÷`), brackets, and equals (`=`) appends and shows key inputs on the screen.
- **Clear Display:** Reset screen input anytime using the `C` button.
- **Clean User Interface:** Styled grid layout with interactive buttons.
- **Responsive Design:** Edge-to-edge support for modern Android devices.

> ℹ️ **Note:** This version focuses on the **Calculator UI and Keypad Input Display**. Mathematical evaluation/calculation logic is not performed.

---

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Framework:** Android XML Layouts
- **Design:** Material Design
- **IDE:** Android Studio

---

## 🚀 How to Run

1. Open **Android Studio**.
2. Select **Open** and choose the `SimpleCalculator` folder.
3. Run the application on an emulator or physical device (`Shift + F10`).

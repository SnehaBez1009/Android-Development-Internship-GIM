# 💼 LinkedIn Profile UI - Sneha Bez

A modern, responsive native Android application replicating the official **LinkedIn Profile Interface**, crafted with **Kotlin**, **XML**, **ConstraintLayout**, and **Material Design 3** components.

## 📱 Features

- **Profile Header & Banner:** Custom cover photo, circular profile avatar, verified badge, pronouns (`She/Her`), headline, and location.
- **Quick Action Bar:** Sleek rounded buttons for **Open to**, **Add section**, and **Enhance profile**.
- **Open to Work Card:** Detailed career preference card indicating recruiter visibility, roles, and preferred job locations.
- **Private Analytics Dashboard:** Interactive cards displaying profile views, post impressions, and search appearances.
- **About & Bio Section:** Comprehensive summary section highlighting skills and technological background.
- **Edge-to-Edge Experience:** Optimized for modern Android devices with dynamic window insets.

---

## 🛠️ Tech Stack & Architecture

- **Language:** Kotlin
- **UI Architecture:** Android XML Layouts, ConstraintLayout, MaterialCardView, NestedScrollView
- **Design System:** Material Design 3 (M3)
- **Build System:** Gradle (Kotlin DSL - `build.gradle.kts`)
- **Compatibility:** Android 7.0 (API Level 24) and above

## 🚀 How to Run the Project

1. Open **Android Studio** (Hedgehog / Iguana / Jellyfish / Ladybug or newer recommended).
2. Click **File > Open...** and select this directory (`Linkdinprofile`).
3. Allow Gradle to sync the dependencies.
4. Connect an Android device (USB debugging enabled) or start an Android Virtual Device (AVD).
5. Click the **Run** button (`Shift + F10`) to build and launch the app.

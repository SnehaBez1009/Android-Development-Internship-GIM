# 🎓 College App View - Task 3

An Android WebView application built with Kotlin to load and navigate the **Panskura Banamali College** portal seamlessly.

---

## 🌟 Features

- **WebView Integration:** Loads the college website inside the app.
- **In-App Navigation:** Keeps web browsing within the application.
- **Back Button Support:** Handles back navigation through web history.

---

## 🛠️ Tech Stack

- **Language:** Kotlin
- **Key Components:** `WebView`, `WebViewClient`, `OnBackPressedCallback`

---

## 🚀 How to Run

1. Open the project in Android Studio.
2. Ensure internet connection on your device or emulator.
3. Build and run the app (`Shift + F10`).
